# Pakalu's Six Pack Quest

A 12-week workout gamification web app. Save the princess.

- Self-hosted on GitHub Pages, state in Supabase `app_state` (doc id `sixpack:state`)
- Mobile-first, add to home screen for the app experience
- Home / Travel tabs share task ids — checking off in either syncs both
- Week-over-week progression (weeks 1/4/7/10 tiers), bosses per world, carryover for missed items
- `APP_VERSION` in index.html drives the self-update watcher; bump it on every ship
